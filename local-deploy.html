🖥️ 本地部署指南

气味档案室 · AI香氛课程工作台 — 在你自己的电脑上运行网站

为什么本地部署？ 本地部署后网站在你电脑上运行，无需联网、永不掉线、数据隐私安全。适合课堂教学、离线使用、数据敏感场景。

📦 方案一：单文件直接打开（最简单）

无需任何服务器，双击 HTML 文件即可在浏览器中使用。

1下载文件

从 GitHub 仓库下载以下核心文件到本地同一个文件夹：

# 方式 A：下载整个仓库（推荐）
git clone https://github.com/YOU-bobo/scent-archive.git

# 方式 B：手动下载单个文件
# 访问 https://github.com/YOU-bobo/scent-archive
# 点击文件 → Download raw file
2双击打开

在下载的文件夹中：

  • 双击 index.html → 打开课程主应用
  • 双击 ppt-standalone.html → 打开 PPT 演示
  • 双击 materials.html → 打开材料清单
限制：单文件直接打开时，PWA（装成 App）和云同步功能可能受限，因为浏览器对 file:// 协议有安全限制。如需完整功能，请用方案二或三。

🖥️ 方案二：Python 本地服务器（推荐课堂教学用）

用 Python 启动本地 HTTP 服务器，所有功能完整可用（PWA、云同步、Service Worker）。

Windows 操作步骤

1安装 Python

访问 https://www.python.org/downloads/ 下载 Python 3.x，安装时勾选 Add Python to PATH。

验证安装：打开命令提示符（Win+R 输入 cmd），运行：

python --version
# 输出 Python 3.10.x 即正常
2下载网站文件

将仓库克隆或下载解压到本地，例如：C:\scent-archive\

cd C:\
git clone https://github.com/YOU-bobo/scent-archive.git
cd scent-archive
3启动服务器 
python -m http.server 8080

看到输出 Serving HTTP on :: port 8080 即启动成功。不要关闭此窗口。

4浏览器访问

打开浏览器，访问：

http://localhost:8080/

macOS 操作步骤

1打开终端

macOS 自带 Python，直接打开终端（Launchpad → 其他 → 终端）。

2下载文件并启动 
cd ~/Desktop
git clone https://github.com/YOU-bobo/scent-archive.git
cd scent-archive
python3 -m http.server 8080
3访问

Safari 或 Chrome 访问 http://localhost:8080/

🌐 方案三：局域网共享（让手机/其他电脑访问）

启动服务器时绑定 0.0.0.0，同一 WiFi 下的设备都能访问。

1启动共享服务器 
# Windows / macOS 通用
python -m http.server 8080 --bind 0.0.0.0
2查看本机 IP 
# Windows
ipconfig | findstr IPv4

# macOS
ifconfig | grep "inet " | grep -v 127

找到类似 192.168.1.100 的地址。

3手机访问

手机连接同一 WiFi，浏览器打开：

http://192.168.1.100:8080/

替换为你电脑的实际 IP 地址。

⚠️ 防火墙提示：Windows 首次启动可能弹窗"Windows 防火墙已阻止此应用"，请勾选专用网络 → 允许访问。macOS 一般无此问题。

📱 本地部署后装成 App

本地服务器（方案二、三）运行后，可装成 PWA App：

平台浏览器操作
📱 AndroidChrome菜单 ⋮ → 添加到主屏幕 / 安装应用
🍎 iOSSafari分享按钮 → 添加到主屏幕
💻 Windows/MacChrome/Edge地址栏右侧安装图标 → 安装

🔄 后续更新网站

如果网站有更新，拉取最新代码即可：

cd scent-archive
git pull origin main

# 重启服务器（Ctrl+C 停止后重新启动）
python -m http.server 8080

❓ 常见问题

Q1：启动服务器后浏览器打不开？

A：检查：

  • 命令提示符窗口是否显示 Serving HTTP on :: port 8080（看到才算启动成功）
  • 端口是否被占用：换端口 python -m http.server 8000
  • 防火墙是否放行（见方案三防火墙提示）

Q2：手机访问 404？

A：确认：

  • 手机和电脑连同一个 WiFi
  • IP 地址正确（用 ipconfig/ifconfig 查询）
  • 电脑防火墙允许该端口（Windows 专用网络）

Q3：PWA 装成 App 后图标不显示？

A：清浏览器缓存后重装。本地部署图标文件必须在同目录。

Q4：不想每次手动启动？

A：用 Node.js + http-server 包安装为全局服务：

# 安装 Node.js 后
npm install -g http-server

# 任意目录运行
http-server -p 8080
