🌸 气味档案室 · 安装说明

AI 香氛课程工作台 · PWA 应用 · 全平台安装指南

📦 应用类型：PWA（渐进式 Web 应用）

📱 支持平台： Android iOS 桌面浏览器

✨ 核心特性：

  • ✅ 独立图标启动（无浏览器地址栏）
  • ✅ 离线可用（首次加载后）
  • ✅ 数据自动保存（本地存储，无需账号）
  • ✅ PDF 导出配方与笔记
  • ✅ 16 周课程内容 + AI 辅助工具

🤖 一、Android 手机安装

1.1 推荐浏览器

使用 Google Chrome（推荐）或 Microsoft Edge 打开应用网址。

💡 Chrome 支持一键弹出"安装应用"提示；其他浏览器需手动操作。

1.2 步骤

第 1 步：用 Chrome 打开应用网址（如 https://你的域名/index.html）
第 2 步：页面加载完成后，有两种安装方式：
方式 A（推荐）：等待 3-5 秒，页面顶部出现提示 📱 "可安装为App"，点击提示即可
方式 B：点击浏览器右上角菜单 ⋮ → 选择 "安装应用" 或 "添加到主屏幕"
第 3 步：弹出确认框"将应用添加到主屏幕"→ 点击 添加
第 4 步：桌面出现 "气味档案" 图标，点击即全屏启动 ✨

1.3 卸载

长按桌面图标 → 选择 卸载 或拖动到"卸载"区域。

🍎 二、iPhone / iPad 安装

2.1 必须使用 Safari

⚠️ 重要：iOS 仅支持 Safari 浏览器安装 PWA。
请不要使用 Chrome、微信浏览器等第三方 App 打开，否则无法"添加到主屏幕"。

2.2 步骤

第 1 步：打开 Safari，访问应用网址（https://你的域名/index.html）
第 2 步：点击屏幕底部的 分享按钮（方框内有箭头 ↑）
第 3 步：在弹出菜单中向下滚动，找到 "添加到主屏幕"
第 4 步：确认名称"气味档案"→ 点击右上角 添加
第 5 步：主屏幕出现图标，点击即全屏启动 ✨

2.3 iOS 小技巧

💡 首次打开 App 时，iOS 会提示"是否允许通知"，可按需选择。
💡 清除 Safari 缓存不会删除 App 内的数据（数据存在 App 沙盒中）。

2.4 卸载

长按主屏幕图标 → 编辑主屏幕 → 点击图标左上角 ×。

🚀 三、部署到 HTTPS 服务器（手机可访问）

⚠️ PWA 要求 HTTPS！localhost 测试没问题，但手机直接访问必须部署到 HTTPS 域名， 否则 Service Worker（离线/安装）无法生效。

推荐 3 种免费方案，任选其一：

3.1 方案 A：GitHub Pages（最常用）

1. 新建 GitHub 仓库：如 scent-archive，设为 Public
2. 上传文件：将以下 6 个文件上传到仓库根目录： 
index.html
manifest.json
sw.js
icon.svg
icon-maskable.svg
materials_10.html
3. 开启 Pages：仓库 Settings → Pages → Branch 选 main → Save
4. 获取网址：等待 1-2 分钟后，页面显示类似： https://你的用户名.github.io/scent-archive/index.html
💡 这是 HTTPS 地址，可直接用于手机安装。自定义域名可在 Pages 设置中配置。

3.2 方案 B：Netlify（拖拽上传，超简单）

1. 访问 app.netlify.com/drop
2. 将 6 个文件打包成 zip（或拖拽文件夹）拖到网页上传区
3. 自动生成地址：https://xxx.netlify.app/，HTTPS 开箱即用
💡 无需注册可匿名使用（但不保留更新权限）。推荐用 GitHub 账号登录后上传，便于后续更新。

3.3 方案 C：Vercel（国内访问较快）

1. 访问 vercel.com，用 GitHub 账号登录
2. 点击"New Project"→ 选择 GitHub 仓库 → Deploy
3. 自动生成地址：https://xxx.vercel.app/
💡 Vercel 国内 CDN 节点多，手机访问速度通常比 GitHub Pages 好。

3.4 部署验证

部署完成后，打开浏览器开发者工具（F12）→ Application 选项卡：

  • 左侧 Manifest：能看到图标、名称等信息 → ✅ 正常
  • 左侧 Service Workers：显示 sw.js 且 status 为 activated → ✅ 正常

💻 四、桌面浏览器使用

4.1 快速打开

直接在 Chrome / Edge / Firefox / Safari 中打开网址即可使用。推荐 Chrome 或 Edge（PWA 功能最全）。

4.2 桌面安装（Chrome / Edge）

第 1 步：打开网址后，地址栏右侧出现 🔽 安装 按钮
第 2 步：点击 → 确认"安装"→ 桌面生成快捷方式
第 3 步：启动后独立窗口运行，像桌面软件
💡 Windows：开始菜单会出现"气味档案"图标；Mac：启动台出现图标。

4.3 导出 PDF

课程内任一周次 → 点击顶部 📄 学习档案 → 🖨 导出PDF → 打印机选择 "另存为PDF"。

💾 五、数据备份与迁移

5.1 数据存储位置

数据保存在浏览器/手机的 localStorage，包括：

  • 每一周的笔记内容
  • 所有配方记录
  • 标签设计方案
  • AI 分析历史

特点：无需账号、无云端同步；卸载 App / 清浏览器缓存 = 数据丢失。请定期备份！

5.2 备份方法（每周做一次）

第 1 步：进入 App → 点击右上角 ⚙ 设置（或设置按钮）
第 2 步：选择 "📦 导出数据" → 下载 JSON 文件
第 3 步：保存到邮箱 / 网盘 / 微信文件传输助手

5.3 恢复 / 迁移到新手机

第 1 步：在新手机安装 App（按上述安装步骤）
第 2 步：打开 App → ⚙ 设置 → "📂 导入数据"
第 3 步：选择之前导出的 JSON 文件 → 确认覆盖
⚠️ 导入会覆盖当前 App 内所有数据，请先导出备份再操作。

🔧 六、常见问题与解决

Q1：桌面能打开，手机提示"无法访问"？

A：localhost 仅本机可访问，需按 第三节 部署到 HTTPS 服务器，手机才能访问。

Q2：手机打开后没有"安装应用"或"添加到主屏幕"选项？

  • Android：确认用的是 Chrome/Edge，且页面完全加载后再打开菜单
  • iOS：必须用 Safari，Chrome 不支持
  • 检查是否为 HTTPS 网址（http:// 开头不行）

Q3：添加到主屏幕后，打开是空白页？

A：Service Worker 缓存版本不一致导致。解决：

  1. 删除桌面图标（卸载 PWA）
  2. 浏览器中清除该站点缓存（Chrome：设置 → 隐私 → 清除浏览数据，勾选"缓存的图片和文件"）
  3. 重新访问网址 → 再次"添加到主屏幕"

Q4：断网后无法打开？

A：首次访问必须联网，之后 Service Worker 自动缓存。解决：

  • 在联网状态下完整打开一次页面
  • Chrome DevTools → Application → Service Workers 确认 status 为 activated

Q5：安卓手机安装后图标太小/模糊？

A：本 App 使用 SVG 矢量图标，可任意缩放不模糊。如果看起来小：

  1. 可能是启动器图标适配问题，换一个手机启动器试试
  2. 或替换 icon.svg 为 PNG 192×192 和 512×512 各一张

Q6：iOS 首次启动有白屏？

A：网络缓存延迟。解决：从主屏幕卸载 App → Safari 清除历史记录 → 重新添加。

Q7：数据丢了怎么办？

A：如果之前有导出 JSON 文件，按 5.3 恢复即可。未备份无法找回，请养成定期导出的习惯。
